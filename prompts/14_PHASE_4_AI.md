/goal Design AI-assisted authoring and personalized practice for ORI Learning without allowing AI to publish unchecked content.

Principle:
AI proposes; ORI reviews; humans publish.

Possible capabilities:
- generate example sentences from approved vocabulary
- propose TOEIC-style distractors
- propose explanations
- generate practice from a learner's recurring errors
- recommend next exercises

Requirements:
- no AI call should expose unnecessary student personal data
- generated content stored as draft
- explicit human approval before publish
- usage/cost controls
- logs for generated drafts
- fallbacks when AI is unavailable

Before implementation, write:
1. use cases
2. data flow
3. privacy risks
4. estimated usage points
5. cheapest viable architecture
